# FAQ Chatbot Using Python

## 📌 Project Overview
The FAQ Chatbot is a Python-based application that answers frequently asked questions automatically. It helps users get quick responses to common questions without needing human assistance.

## 🎯 Objectives
- To automate answers to frequently asked questions.
- To reduce the time required to find information.
- To understand the basics of Natural Language Processing (NLP).
- To develop a simple and interactive chatbot using Python.

## 🛠️ Technologies Used
- **Python** – Programming language
- **NLTK** – Natural Language Processing toolkit
- **VS Code / Google Colab** – Development environment

## ⚙️ Features
- Accepts user questions as input.
- Matches questions with predefined FAQs.
- Provides automatic responses.
- Supports continuous interaction with the user.
- Displays a fallback message when it cannot find a suitable answer.

## 🚀 Installation and Execution

### Step 1: Install Python
Install Python on your computer if it is not already installed.

### Step 2: Install Required Library
Open the terminal and run:

```bash
pip install nltk
```

### Step 3: Run the Chatbot
Navigate to the project folder and execute:

```bash
python faq_chatbot.py
```

### Step 4: Ask Questions
Type a question in the chatbot and press Enter to receive a response.

## 💡 Example

**User:** Hi

**Chatbot:** Hello! How can I help you?

**User:** What is Python?

**Chatbot:** Python is a popular programming language.

*Note: The actual responses depend on the FAQs defined in the project code.*
